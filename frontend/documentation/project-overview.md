
# Project Overview

## 1. Purpose

To develop an online platform for personalized journaling products and stationery collections.

## 2. Main User Types

### Customers
- Browse monthly themes.
- Customize stationery products.
- Submit design requests.
- Approve artwork previews.
- Place and track orders.

### Administrators
- Manage monthly themes.
- Manage products and prices.
- Review customization requests.
- Prepare artwork prompts.
- Upload artwork previews.
- Manage customer orders.

## 3. Main Modules

1. Customer Management
2. Theme Management
3. Product Management
4. Customization Management
5. Artwork and Approval Management
6. Order Management
7. Admin Dashboard

## 4. Business Workflow

Customer selects theme
→ Customizes preferences
→ Submits request
→ Admin prepares prompt
→ Admin creates artwork manually
→ Artwork preview uploaded
→ Customer approves design
→ Order enters production
→ Order dispatched
→ Order delivered
